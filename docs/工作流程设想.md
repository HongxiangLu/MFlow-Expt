前置条件：
    1.数据库内存有大量的数据(id、name、url、type、status)
        id主键、name名字、url：模型存储路径、type：种类(例如青铜器、画等)、status状态：展示、不展示等-------------后续可能还需要细分：例如文物id，文物信息、所在博物馆、所在展览等细节

    2.后台管理系统
        用于管理当前博物馆/数据库所存在的展品，调整数据、状态等

一、工作流程
    1.工作人员登录后台管理系统
    2.进入文物管理页面
    3.通过分类迅速定位还没有3d模型/信息缺失的物品---或新增物品
    4.工作人员上传主图(如缺失)，并上传要生成3d模型的参照图(调用腾讯混元3d api)
    ......混元3d调用流程，参考3D.md
    5.生成成功后文物/模型的状态变为待审查                  <------------------------------
        maybe新增一个管理模块，用于工作人员快速审查模型                                   |
    6.两个按钮----如确定则会调用后台接口，将文物信息与模型相绑定(数据库url指向)             |
             |                                                                        |
             ----如过不确定则弹出弹窗----重新上传图片/旧有图片(抽奖)-----------------------
